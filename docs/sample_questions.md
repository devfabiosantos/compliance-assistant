# Perguntas de exemplo

Este documento contém perguntas representativas que o Compliance Assistant deve ser capaz de responder. Ele serve como entrada manual para validação e como base para o arquivo `evaluation/questions.json`.

## Base legal e LGPD

1. O que é dado pessoal segundo a LGPD?
2. O que caracteriza um dado pessoal sensível? Cite exemplos.
3. Quem é o titular de dados pessoais?
4. O que é tratamento de dados pessoais?
5. Quais são os princípios da LGPD previstos no Artigo 6?
6. Qual o papel da ANPD na aplicação da LGPD?
7. Em que situações o tratamento de dados pode ser dispensado de registro no RIPD?
8. Quais direitos do titular previstos na LGPD são relevantes no dia a dia corporativo?
9. O que o controlador deve fazer em caso de incidente de segurança que envolva dados pessoais?
10. Qual o prazo para comunicação de incidente à ANPD e aos titulares?
