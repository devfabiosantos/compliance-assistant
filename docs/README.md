# Documentos do projeto

Pasta central de documentação do Compliance Assistant.

## O que contém

- `oficiais/` — LGPD, guias e FAQs da ANPD.
- `empresa/` — documentos corporativos da NovaData Solutions (Markdown como fonte).
- `adr/` — **Architecture Decision Records**: decisões arquiteturais relevantes do projeto.
- `sample_questions.md` — perguntas-referência para validação do RAG.

## Ciclo de vida

- Na Sprint 2, os primeiros documentos corporativos serão adicionados em `empresa/`.
- Sempre que uma decisão técnica importante for tomada, adicione um novo ADR em `adr/`, com número sequencial (`0004-...md`), data e status.
