# Documentos oficiais

Pasta reservada para os documentos de referência oficiais relacionados à LGPD e ANPD.

## Conteúdo esperado

- `LGPD.pdf` — Lei Geral de Proteção de Dados (Lei nº 13.709/2018).
- `Guia_ANPD.pdf` — guia(s) e cartilhas oficiais da ANPD.
- `FAQ_ANPD.pdf` — perguntas frequentes publicadas pela ANPD.

## Observações

- Coloque os arquivos PDF nesta pasta. Eles serão ignorados por padrão no Git (ver `.gitignore`), pois são artefatos de referência.
- A indexação é feita por meio do `DocumentLoader`, que lê PDFs via `PyPDF`.
- Para manter rastreabilidade, prefira as versões oficiais extraídas diretamente do site da ANPD e da Câmara dos Deputados.
